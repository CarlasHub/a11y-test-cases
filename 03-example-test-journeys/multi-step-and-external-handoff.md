# Multi-step and external handoff journey

## Goal

Follow a complete user path from a detail page to confirmation or the authorised end of the test scope.

## Steps

1. Record the starting page, site language, destination and responsible platform.
2. Activate the next action with keyboard and pointer input.
3. Confirm new windows, domains and context changes are understandable.
4. Complete sign-in or account creation with safe test credentials when authorised.
5. Test password-manager paste and other supported authentication alternatives.
6. Complete every step, including validation, document upload, review, correction and confirmation when in scope.
7. Confirm earlier information is reused instead of unnecessarily requested again.
8. Approach any session timeout and confirm warning, extension and data preservation.
9. Before final submission, confirm consequential information can be reviewed and corrected.
10. Record every page and state in the complete process, including third-party pages.

## Boundary

If the destination cannot be tested, record the handoff as blocked and leave affected criterion outcomes empty. Do not report the complete process as passed.

## Related tests

Run every applicable test, with particular attention to TC-07 and TC-11 through TC-13.
