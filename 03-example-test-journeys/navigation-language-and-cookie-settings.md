# Navigation, language and cookie-settings journey

## Goal

Use repeated site navigation, change language and manage cookie preferences without a pointer.

## Steps

1. Start at the top of the homepage and use the skip link.
2. Open and close every primary navigation level with keyboard only.
3. Confirm expanded state, focus order, Escape behaviour and focus return.
4. Repeat with the responsive mobile menu.
5. Open the language selector, identify the current language and choose another supported language.
6. Confirm the destination language, page language and equivalent-page behaviour.
7. Open cookie settings, review categories, change a preference and save it.
8. Reopen settings and confirm the saved state is exposed visually and programmatically.
9. Compare header, footer, help and repeated components across representative pages.
