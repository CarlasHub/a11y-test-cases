# Homepage journey

## Scope

Test the homepage in each representative language and responsive layout.

## Steps

1. Load the page from a clean session and handle the cookie notice using keyboard only.
2. Use the skip link, primary navigation, language picker and mobile menu.
3. Identify the page title, main heading, landmarks and content order.
4. Operate the main search form, including autocomplete or geolocation if supplied.
5. Pause or stop automatically moving hero content, video or carousels.
6. Follow featured content cards; confirm repeated link names have sufficient context.
7. Increase text to 200 percent and browser zoom to the equivalent of a 320 CSS-pixel viewport.
8. Repeat meaningful touch interactions on a physical mobile device where required.

## Required states

- cookie notice open and closed;
- navigation and language menus open and closed;
- search fields empty, populated and invalid;
- carousel or media moving and paused;
- desktop and mobile layouts.

## Related tests

Run TC-01 through TC-07, TC-09 through TC-12, and any applicable media or flashing tests.
