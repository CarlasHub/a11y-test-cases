# Glossary

## Accessible name

The programmatic name assistive technologies use to identify a control or element. It may come from visible text, a label, alternative text or another supported naming method.

## Accessibility tree

The browser's representation of roles, names, states, values and relationships exposed to assistive technologies. It is diagnostic evidence, not a screen reader.

## Change of context

A substantial change such as navigation, opening a new window, moving focus or changing content in a way that changes the meaning of the page without warning.

## Complete process

Every ordered page or step required to complete an activity, such as finding an item and completing a registration.

## CSS pixel

The browser layout unit used by WCAG measurements. It is not necessarily one physical device pixel.

## Focus

The current keyboard-interaction location. The focused element receives keyboard input.

## Programmatically determined

Information exposed in a form that software, including assistive technology, can identify and present to users.

## Representative sample

A recorded selection covering unique templates, shared components, critical journeys, languages, states and known risks. A sample does not prove that untested content passes.

## Status message

A content change that provides information about the result of an action, waiting state, progress or errors without changing context.

## User interface component

A distinct control that users perceive as performing one function, such as a button, input, link, checkbox, tab or custom widget.
