# Tool setup

Use tools approved by the Radancy project or customer environment. Record exact versions because rule coverage and output can change.

## Browser preparation

1. Create a clean browser profile for the test run.
2. Install only approved accessibility extensions.
3. Disable extensions unrelated to testing.
4. Confirm browser zoom is 100 percent before recording the baseline viewport.
5. Record stored site preferences that could suppress notices, motion or media.

## Required capabilities

- Automated WCAG page check.
- Browser accessibility-tree and computed-name inspection.
- Heading and landmark outline.
- Foreground/background colour sampling with contrast calculation.
- CSS-pixel viewport and target measurement.
- Text-spacing style application.
- Screen reader on an approved real platform.
- Objective flash analysis for suspected flashing content.

## Calibration

Before a formal test run, practise each tool on a known passing example and a known failing example. Record tool limitations. A tool that reports no issue must not be assumed to test the complete success criterion.
